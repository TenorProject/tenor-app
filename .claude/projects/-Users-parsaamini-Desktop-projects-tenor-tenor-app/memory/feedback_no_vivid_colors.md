Don't use vivid accent colors like violet, amber, emerald for UI components. Stick to the zinc color palette and white buttons that the rest of the app uses. Vivid colors make it obvious that AI generated the code.

**Why:** User finds that Claude's default color choices (violet, emerald, amber accents) are a telltale sign of AI-generated UI.

**How to apply:** When building any UI component, use zinc tones for borders/backgrounds/text and white for primary buttons — match the existing app style rather than introducing new accent colors.
